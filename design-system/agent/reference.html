HTTP API

CoreApi routes

Everything lives under the shared REST API (/readysetcloud/api-url in SSM), behind a Cognito JWT.

Method & pathBodyReturns
POST /agent/sessions{ systemPrompt?, modelId?, temperature?, maxTokens?, title?, tools?, mcpServers? }{ sessionId }; the caller is the owner
POST /agent/connect{ sessionId }{ wsUrl }; auth is the bearer subprotocol on the socket
POST /agent/tasks{ request, sessionId?, wait?, system? }200 result envelope, or 202 { taskId, status }
GET /agent/tasks/{taskId}The result envelope; owner (or createdBy) only

Storage

Single-table keys

One DynamoDB table with pk/sk and a TTL on expiresAt.

ItempkskNotes
SnapshotsSESSION#{sessionId}SNAPSHOT#…, LATEST#…, MANIFEST#…Strands conversation state; 30-day TTL
Session configSESSION#{sessionId}CONFIGOwner, prompt, model, tools, MCP specs
Task recordTASK#{taskId}STATUSStatus and result; 24-hour TTL
Agent stateAGENT#{agentId}STATE#{name}[#{scope}]Revision-checked documents; definePersistentAgent uses <type>.agenda, <type>.commitments, and <type>.usage (the task cap). In your table, for persistent agents.
Trigger gateTRIGGER#{[prefix#]slot}GATEowner, lastTriggeredAt; 30-day TTL
Nobody reads this table from another stack. Results cross as Agent Task Completed events and session requests cross as Create Agent Session.
